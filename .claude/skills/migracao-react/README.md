# migracao-react

Skill do Claude Code que migra um portfólio feito em HTML/CSS para React + TypeScript com Vite, uma seção por vez, mantendo o visual original.

**Como usar em outro projeto:** copie a pasta `migracao-react/` para dentro de `.claude/skills/` do seu repositório e reinicie o Claude Code. Depois peça algo como "migra a seção de projetos do portfólio para React".

Arquivos: `SKILL.md` (regras e formato de resposta) e `reference.md` (exemplos, checklist e padrão de commits, lidos sob demanda).
